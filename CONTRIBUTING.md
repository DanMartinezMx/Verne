# Contribuir a Verne

Gracias por tu interés. Antes de nada, honestidad total sobre cómo funciona este proyecto:

**Verne es el proyecto personal de un solo maintainer, que lo construye primero para sí
mismo.** El código es libre (AGPL-3.0) y siempre lo será, pero esto no es (todavía) un
proyecto comunitario:

- **Issues:** bienvenidos, especialmente reportes de bugs con pasos para reproducir y, sobre
  todo, cualquier bug de pérdida de datos (esos tienen prioridad absoluta).
- **Pull requests:** puedes abrirlos, pero sin garantía de revisión rápida ni de aceptación.
  Para cambios que no sean triviales, abre primero un issue para hablarlo — te puede ahorrar
  trabajo.
- **Decisiones:** las toma el maintainer (modelo dictador benevolente). Las decisiones
  grandes quedan registradas con su razonamiento en [`rfcs/`](rfcs/); leerlas es la mejor
  forma de entender por qué Verne es como es.
- **Rumbo:** el mapa a largo plazo es el [RFC-0001](rfcs/0001-vision-y-arquitectura.md); el
  alcance actual es el [RFC-0002](rfcs/0002-alcance-solo-dev.md). Lo que está fuera de
  alcance ahí, está fuera de alcance aquí.

Si contribuyes código, se te pedirá `Signed-off-by` (DCO) en los commits.

Siempre puedes hacer un fork: para eso es libre. Y si el proyecto crece hasta necesitar más
manos y más gobernanza, este documento cambiará — también por escrito.
